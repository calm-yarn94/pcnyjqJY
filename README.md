# 项目简介

## 核心功能
- 基于YOLOv8的生活垃圾实例分割检测系统
- 支持图片、视频及摄像头进行检测
- 支持选择模型
- 界面实时显示目标位置、目标总数、置信度等信息
- 支持批量检测并在界面直接查看所有检测结果
- 支持检测结果保存
- 可选择显示标签和原图
- 可自定义置信度，IOU阈值

## 适用场景
- 生活垃圾分类检测与管理
- 环保监测与研究
- 智能垃圾分类设备开发
- 环境保护相关应用开发

## 技术特点
- 使用Pycharm+Anaconda（或VSCode+Anaconda）开发
- 环境要求：python3.9、opencv-python、PyQt5、ultralytics、torch1.9等
- 包含完整源码、数据集（3300张图片，包含1类'trash'）、训练好的模型及训练结果
- 提供项目运行教程和完整的程序文件
- 已训练好模型，配置成功环境可直接使用
